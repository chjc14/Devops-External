3. Step 2 – Create Calculator.java
Create Calculator.java and paste this code:
import java.util.Scanner;

public class Calculator {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.println("Simple Calculator");

        System.out.print("Enter first number: ");
        double a = sc.nextDouble();

        System.out.print("Enter second number: ");
        double b = sc.nextDouble();

        System.out.println("1. Addition");
        System.out.println("2. Subtraction");
        System.out.println("3. Multiplication");
        System.out.println("4. Division");

        System.out.print("Enter choice: ");
        int choice = sc.nextInt();

        switch (choice) {
            case 1:
                System.out.println("Result: " + (a + b));
                break;

            case 2:
                System.out.println("Result: " + (a - b));
                break;

            case 3:
                System.out.println("Result: " + (a * b));
                break;

            case 4:
                if (b != 0)
                    System.out.println("Result: " + (a / b));
                else
                    System.out.println("Cannot divide by zero");
                break;

            default:
                System.out.println("Invalid choice");
        }

        sc.close();
    }
}


4. Step 3 – Create Dockerfile
Create a file named Dockerfile:
FROM eclipse-temurin:17-jdk

WORKDIR /app

COPY Calculator.java .

RUN javac Calculator.java

CMD ["java", "Calculator"]


Explanation:
- FROM: Uses Java 17 JDK image.
- WORKDIR: Sets working directory.
- COPY: Copies Java source code into the image.
- RUN: Compiles Java program.
- CMD: Executes the calculator.
5. Step 4 – Pull Java Docker image
docker pull eclipse-temurin:17-jdk


6. Step 5 – Build Docker image
docker build -t java-calculator .


Expected output:
Successfully tagged java-calculator:latest


Verify:
docker images


7. Step 6 – Create and run interactive container
Execute:
docker run -it --name calculator-container java-calculator


Here:
- -i: Keeps standard input open.
- -t: Creates a terminal.
- --name: Assigns a container name.

Revised Jenkinsfile
Use this simpler pipeline:
pipeline {

    agent any

    triggers {
        pollSCM('H/2 * * * *')
    }

    stages {

        stage('Checkout') {
            steps {
                checkout scm
            }
        }

        stage('Build') {
            steps {
                echo 'Weekly Timetable Build Successful'
            }
        }

        stage('Test') {
            steps {
                bat 'if exist index.html (echo HTML file found) else (exit /b 1)'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Weekly Timetable Deployment Successful'
            }
        }
    }
}
